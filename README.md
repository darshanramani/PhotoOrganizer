# Thunder Bay Gallery Application  
## COMP5450 – Challenge 1  
### Group 7 – Photo Organizer Application  

Thunder Bay Gallery is a modern photo gallery application developed using **Kotlin** and **Jetpack Compose** in Android Studio.

The application allows users to organize Thunder Bay memories into folders, browse all photos together, switch between grid/list layouts, mark favorite photos, use slideshow mode, and dynamically manage folders and photos.

The app focuses on clean UI design, responsive layouts, and interactive gallery management experience.

# Main Features

## 1. All Photos Home Screen
- Displays all photos together
- Responsive gallery layout
- Thunder Bay themed gallery interface
- Modern card-based UI

---

## 2. Folder Management System
- Create custom folders
- Delete folders
- Dynamic folder cover images
- Empty folder handling
- Open folder view functionality

---

## 3. Grid / List View System
- Grid layout support
- List layout support
- Dynamic column selection:
  - 2-column large view
  - 3-column medium view
  - 4-column compact view

---

## 4. Favorite Photo System
- Mark/unmark favorite photos
- Filter favorite photos only
- Favorite icon support

---

## 5. Dark Mode / Light Mode
- User can switch themes dynamically
- Entire UI updates automatically
- Modern dark UI support

---

## 6. Slideshow Functionality
- View all photos in slideshow mode
- Navigate previous/next photos
- Folder-based slideshow support

---

## 7. Photo Detail Screen
- Large image preview
- Remove photo functionality
- Folder information display
